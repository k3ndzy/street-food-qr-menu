# 📱 Street Food QR Menu & Direct Kitchen Orders

Hệ thống Quét mã QR Menu tại bàn & Chuyển thẳng đơn xuống Bếp cho Quán ăn bình dân bằng Go

Một dự án mẫu mã nguồn mở được **tự xây dựng từ con số 0 (build from scratch) bằng Go**, tuân thủ nguyên tắc Clean Code và kiến trúc dịch vụ độc lập, sẵn sàng mở rộng cho các hệ thống quản lý kinh doanh F&B, Salon & E-Commerce.

---

## ⚡ Tính năng Cốt lõi
* **Logic nghiệp vụ phân tầng:** Mô hình hóa các thực thể kinh doanh rõ ràng.
* **Đồng bộ đa luồng (Thread-safe):** Đảm bảo tính toàn vẹn dữ liệu đơn hàng và lịch hẹn.
* **Kiểm thử tự động:** Tích hợp sẵn Unit Test với độ tin cậy 100%.
* **Zero Dependencies:** Viết thuần chuẩn Go 100%, không cần cài thêm thư viện rườm rà.
